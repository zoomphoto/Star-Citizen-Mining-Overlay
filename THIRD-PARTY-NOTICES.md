## 1. Upstream Inspiration & Bundled Assets — Niteb1rd/IRIS

- **Project**: [IRIS](https://github.com/Niteb1rd/IRIS)
- **Author**: Niteb1rd and contributors
- **License**: GNU General Public License v3.0 (`GPL-3.0`)

SC Overlay is a cross-platform Rust implementation inspired by [Niteb1rd/IRIS](https://github.com/Niteb1rd/IRIS), maintaining 100% file-format compatibility (`social-config.txt`, `settings.txt`, `mining.txt`, `exclusions.txt`, `dossier-notes.txt`, and `Data/cache.db`) and bundling the following GPL-3.0 assets from IRIS:
- `assets/letters-model.bin` — 2-layer MLP glyph classifier weights trained on synthetic Star Citizen HUD character crops
- `assets/mining.txt` — Star Citizen 4.7 mining radar signal signature table
- `assets/exclusions.txt` — Default Star Citizen HUD & ship UI token exclusion list
- `assets/settings.txt` & `assets/social-config.txt` — Default commented configuration templates
- `assets/iris-on.ico`, `assets/iris-off.ico`, `assets/tray-on.ico`, `assets/tray-off.ico` — Application and system tray icons
